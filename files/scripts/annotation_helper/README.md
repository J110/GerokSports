# Delivery detail annotation helper

Manual **Path 2/3** ground-truth labeling for delivery clips vs `layer2.json` (Qwen / `cricket_values`). **Stdlib only** — no pip installs.

## Layout

| File | Purpose |
|------|---------|
| `sample.txt` | Stratified delivery list (30 rows, `delivery_id` + tab + `window_source`) |
| `annotate.py` | Interactive prompts → `annotations.csv` |
| `analyze.py` | Metrics + “fabrication” table → stdout and `annotations_analysis.md` |
| `annotations.csv` | Created on first annotation run (gitignored if you add it) |
| `annotations_analysis.md` | Generated by `analyze.py` |

Default session: `files/logs/deliveries/20260430_195352/` (override with `--deliveries`).

## How to annotate

1. Work from a comfortable directory; clips are ~12.5 s (fallback) or ~3.5 s (retrospective).
2. From the **repository root**:
   ```bash
   python3 files/scripts/annotation_helper/annotate.py
   ```
3. For each delivery: read the printed model table, watch the opened MP4 (`open` on macOS, `xdg-open` on Linux). If the player does not start, the script prints the **absolute path** — open it manually.
4. Answer menus with a **number**, **`u`** (unknown), or **`s`** (skip rest of ground-truth fields for this delivery; remaining GT columns are stored as `skip`).
5. Add optional free-form **notes** after each delivery.
6. **Pause and resume:** stop with Ctrl+C if needed; re-run with `--resume` to skip `delivery_id` values already in `annotations.csv`.

### Flags

```text
--sample-file PATH   default: files/scripts/annotation_helper/sample.txt
--output PATH        default: files/scripts/annotation_helper/annotations.csv
--deliveries PATH    default: files/logs/deliveries/20260430_195352
--resume             skip deliveries already present in the output CSV
```

### Ground-truth menus (aligned with model enums where possible)

- **Length:** yorker, full, good_length, short_of_length, short, bouncer (+ u, s).
- **Line:** outside_off, off_stump, middle, leg_stump, outside_leg.
- **Shot type:** pull, cut, flick, defend (matches dominant `shot_type` values in the GT-RCB run).
- **Shot side:** off, leg, straight.
- **Shot angle:** cover, mid_off, straight, mid_on, square, down_ground, mid, square_leg, fine_leg, point, third_man.
- **Handedness:** right, left (+ u → unknown).

`bowling_arm` / `bowling_angle` are omitted (uniformly unknown in production logs).

## How to analyze

```bash
python3 files/scripts/annotation_helper/analyze.py
```

Optional:

```text
--input PATH   default: annotations.csv next to this README
--output PATH  default: annotations_analysis.md
```

The report includes:

- Per-field accuracy (GT must not be `unknown` or `skip` to count).
- Length accuracy vs **bounce_visible** and vs **window_source**.
- **Fabrication detector:** wrong predictions with model confidence ≥ **0.7**, top 5 per field by confidence.
